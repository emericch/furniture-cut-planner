# Débit Rapide

Outil de menuiserie pour générer des feuilles de débit de meubles : calcul des panneaux, sens du fil, regroupement des pièces identiques, impression et export PDF.

Créé par Emeric Chenay.

**Site** : https://debit-rapide.pages.dev

## Développement local

Prérequis : Node.js et npm.

```sh
npm install
npm run dev     # serveur de développement
npm run test    # tests des calculs
npm run build   # version de production dans dist/
```

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
